# ASTRA — Person 1 backend (Blockchain Data, Graph & API)

Modular-monolith FastAPI service: canonical transfer schemas → deterministic **synthetic** scenario → Etherscan provider adapter
(timeouts, bounded retries, rate-limit handling, TTL cache, explicit degraded mode) → directed time-aware graph → bounded path
tracing → REST API. Graph connectivity is an observed relationship, **not proof of common ownership**.

## Quick start (no API key, no internet needed)
```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
pytest                                                     # 104 tests
uvicorn app.main:app --port 8000                           # docs: http://127.0.0.1:8000/docs
# in another terminal, from the repo root:
python scripts/clean_start_check.py http://127.0.0.1:8000
```
Demo case id for the frontend: `inv-ghost_attacks_synthetic_v1` (pre-created at startup, `data_mode: "synthetic"`).

## Live wallet queries (optional)
```bash
cp .env.example .env     # set ETHERSCAN_API_KEY (server-side only; never in the frontend)
cd backend && uvicorn app.main:app --port 8000 --env-file ../.env
```
Without a key, wallet queries return `503 PROVIDER_NOT_CONFIGURED` with `degraded_mode: true` — never silent synthetic data.

## Layout
```
backend/app/schemas/            Pydantic models (transaction, graph/API, common/error envelope)
backend/app/services/ingestion/ normalizer.py (validate+normalize+dedupe) · providers.py (Etherscan) · service.py
backend/app/services/graph_engine/engine.py   NetworkX multigraph + bounded BFS path tracing
backend/app/api/routes.py       endpoints (Person 2 endpoints are 501 stubs)
backend/tests/                  102 pytest tests
data/scenarios/                 ghost_attacks_synthetic_v1.json (generated by scripts/generate_scenario.py)
docs/api-contract.md            handover: JSON contracts, data-mode semantics, limitations
docs/examples/                  real captured responses
```
